# Contributing

This repository is generated from https://h5.2113.net/ every time the site is published, so edits to README.md, apps.json or apps.csv made by pull request would be overwritten. Please open an issue instead.

## Report a mistake

Open an issue, or email zmkm568@gmail.com, with:

- the app and its package name;
- what is wrong (for example the version, source, signer, licence or category);
- a link to an official source that shows the right value: the project’s repository or release page, or its F-Droid or IzzyOnDroid listing.

We check it against the official source and fix the site; the correction appears here with the next update.

## Developers

If you develop one of these apps and want it removed or its text changed, open an issue or email us. Removal requests are handled the same day. See https://h5.2113.net/developers.html.

## Suggest an app

Suggestions are welcome as issues. We only list open-source apps whose licence allows redistribution, and only files we can check against an official source.
